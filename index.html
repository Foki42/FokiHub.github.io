4 МЕТОДА ПОЛЁТА

Каждый метод работает по-своему — подбирай под игру и нужное поведение.

01
MaskedFly
Основной метод полёта. Маскирует движение через BodyVelocity, обходя стандартную физику персонажа. Минимальный риск обнаружения, плавное управление в любой игре.
02
BodyVelocity
Прямое применение BodyVelocity к HumanoidRootPart. Быстрый отклик, высокая скорость. Оптимален для открытых карт без сложной геометрии и коллизий.
03
CFrame Fly
Телепортирует персонажа покадрово через CFrame.Lerp. Проходит сквозь коллизии, абсолютная позиционная точность. Используй совместно с FlyInertia для плавности.
04
Noclip Fly
Комбинирует NoClip и полётный вектор. Персонаж проходит через любые препятствия во время полёта. Идеально для исследования закрытых зон и подземелий.
// Teleport System

4 МЕТОДА ТЕЛЕПОРТА

Разные механики для разных ситуаций и типов игр.

01
CFrame
Мгновенный телепорт через прямое изменение CFrame персонажа. Нет анимации, нет задержки — самый быстрый метод. Работает в любой игре без ограничений.
02
Tween
Плавное перемещение через TweenService с настраиваемой скоростью. Визуально выглядит как быстрый рывок — менее заметно для других игроков на сервере.
03
AlignPos
Использует AlignPosition constraint для физически корректного перемещения. Взаимодействует с коллизиями, реалистично выглядит в играх с активной физикой.
04
MoveTo
Телепорт через Humanoid:MoveTo() — движение с обходом препятствий. Наиболее нативный метод, использует встроенный pathfinding движка Roblox.
